# 📚 Library Management System

A full-stack Library Management System built using **HTML, CSS, JavaScript, Node.js and Express.js**.

The application allows users to manage books, members, authors and borrowing records through a simple web-based dashboard.

## 🚀 Live Demo

**Frontend:**  
https://librarymanagementbackend-1-599n.onrender.com

**Backend API:**  
https://librarymanagementbackend-api.onrender.com

---

## ✨ Features

### 📖 Book Management
- Add new books
- View all books
- Update book details
- Delete books
- Search books
- Filter books by availability
- Pagination
- Issue books
- Return books
- Prevent issuing an already issued book

### 👤 Member Management
- Add members
- View members
- Update member details
- Delete members
- Search members by name
- Filter members by membership type
- Pagination

### ✍️ Author Management
- Add authors
- View authors
- Update author details
- Delete authors

### 📋 Borrowing Management
- Track issued books
- Store member and book information
- Record issue date
- Record return date
- View borrowing history

### 📊 Dashboard
- Total books
- Total members
- Total authors
- Borrowing records
